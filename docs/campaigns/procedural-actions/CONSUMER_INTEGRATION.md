## Existing crawler jab

Retain the game phase clock and `Evaluate_ActionOffset` through the public manual action surface. This preserves every existing `ECk_TweenEasing` choice and the established cancellation/acknowledgement behavior; converting to managed clips would narrow the existing profile's easing vocabulary. Managed clips are demonstrated independently with authored limb choreography.

An armed crawler owns an ActionPlayer on its existing articulation. Each jab creates one scoped body-channel action. The game waits for Ready before advancing its pose clock. Exactly one complete pose batch may be in flight; the game waits for its matching accepted receipt before advancing or submitting again. Each batch carries the game's monotonically increasing sample ID as CorrelationToken. The resolver accepts only a successful observed receipt with the matching correlation token, a new subject-pose revision, and a body presentation matching the settled visual entity. Request completion is never that acknowledgement.

The game keeps target selection, cancellation priority, phase transitions, root/facing displacement guards, sphere sweep, candidate mailbox and damage deduplication. BodyPose's legacy action-offset writer is removed from this adapter because the ActionPlayer owns presentation while attached. SurfaceMotion remains the sole root mover.

On normal completion, the game acknowledges its neutral endpoint, requests End once, and waits for terminal recovery before destroying the action scope and admitting another jab. Keep the scope, player and copied stream identity until the terminal page has been consumed and the stream released. Cancellation that can ease out continues the existing CancelRecover poses while the token remains Ready: library Cancel clears pending input, so it must not precede those poses. Loss of the subject/controller closes offensive behavior immediately and follows the library's finite return/terminal state. Both manual InputTimeout and PublicationTimeout must exceed the game's pose-acknowledgement watchdog so they do not silently replace the existing timeout contract. Every path drains/acknowledges its own receipt stream, with explicit handling for gaps and terminal failure.

Existing tests that deliberately overwrite BodyPose must change their fault injection: that writer is correctly rejected after migration. The game watchdog fixture should explicitly drop the game acknowledgement; the library's independent late-writer fixture continues to prove publication failure. Tests must assert actual neutral presentation and completed ownership return, not the now-unused legacy offset getter.

Acceptance: unchanged CrawlerMelee assertions for phase sequence, one damage event, stationary overlap, wall obstruction, moving target, root/facing drift, cancellation and finite recovery, plus sampled pre/post pose comparison and continuous visual observation. Pre-change 22/22 evidence is in `Saved/Logs/CrawlerMelee-Final-Summary.txt`; it is historical baseline evidence, not verification of the new adapter.

## Long-limb collision demonstration

The consumer must declare its collision trajectory. This demonstration uses the piecewise linear path between joint positions in accepted observations and their qualified evaluated samples. Evaluated samples are labelled as evaluations; they are not represented as separately rendered or physically observed frames. It makes no claim about an unobserved continuous rigid-body arc between those points. Receipts provide centered segment transforms, not joints. Freeze the admitted topology and segment lengths with the action; reconstruct each segment endpoint as center +/- GetRotation().GetAxisX() * length / 2 (rotation only; visual part scale does not change solver length), matching the production rig convention. Validate segment count, finite transforms with normalized rotations, matching topology revision and adjoining endpoints within 0.05 cm for each interval; close on mismatch.

For one linear interval, let a segment's endpoints be A(t), B(t), each linear in t. At fixed material coordinates u_i spanning [0,1], C_i(t) = (1-u_i) A(t) + u_i B(t) is also linear. If maximum adjacent coordinate spacing is d and maximum endpoint segment length is L, every centerline point lies within L*d/2 of a sampled center throughout the interval. Sweeping a sphere of radius r + L*d/2 at each C_i therefore conservatively covers the complete deforming capsule of radius r. This is a derived spatial error bound, not a sample-count claim. Authoring chooses a maximum extra radius; insufficient sample capacity rejects the move.

The inflated swept spheres are the demonstration's declared gameplay hit volume, including their bounded extra reach. They are not an exact capsule-contact-time estimator. Use the same inflated spheres for static world obstruction and targets; retain the earliest wall and target under this same proxy and suppress damage when a wall occurs first (including ties within tolerance). Demonstration targets are explicit spheres with known previous/current centers; relative center sweeps account for linear target motion in the same interval. A game wanting arbitrary moving target shapes or moving obstacles needs an additional declared collision adapter, not an implicit expansion of this proof.

The world adapter uses Jolt's closest-hit query with `StaticNonSensor` body selection, including initial overlap for zero travel. Dynamic bodies and probe sensors are excluded before collection; it does not allocate and sort every probe hit for each proxy. Static bodies are assumed unchanged over the recorded interval. The explicit target sphere is centered on the entity owning its damage zone, with a registered live hurtbox of that same zone. Attach rejects mismatched pairs atomically, and the consumer revalidates the pair before using retained geometry; a destroyed, disabled or replaced binding closes the window. These policies belong to the game demonstration, not the action library.

Action playback/service time is not world observation time. Retain target centers at the same two world observation boundaries as the accepted subject poses, keyed by pose revision; map qualified evaluated-sample fractions into that exact bracket. Delayed receipt consumption must use this retained bracket, never the target's current position at drain time. Missing, stale or discontinuous history closes the window. The demonstration explicitly assumes linear target motion within each captured world bracket.

Discontinuities, stream gaps, topology changes, missing joint geometry, unsupported target shapes or exhausted geometry budgets close the damage window without bridging the missing path. A game-owned window generation and target identity suppress duplicate damage across segments/samples. Terminal closure is consumed in stream order: earlier accepted intervals keep their meaning, while cancellation/severing cannot authorize subsequent geometry.

Required demonstration cases: midpoint hit with missed tip, subdivided fast arc, wall before target, linearly moving target, repeated segment contact producing one damage event, terminal cancellation/sever, requested/accepted disagreement, and target-binding rejection. Verify the bound and rejection paths independently of Jolt; then exercise real world queries and game receipts. This is a dedicated-articulation demonstration; it does not certify a complete walking-crawler leg-strike behavior. Framework borrowed-limb fixtures separately verify gait withdrawal and recovery.
